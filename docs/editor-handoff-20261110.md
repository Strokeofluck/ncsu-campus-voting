# Editor handoff

[Live editor preview](https://strokeofluck.github.io/ncsu-campus-voting/article/editor-preview-20261109-v2.html?view=1)

[Download editor package](https://strokeofluck.github.io/ncsu-campus-voting/downloads/technician-editor-package-20261110.zip)

Paste each complete block into one CMS Custom HTML block. Resizing is included in each block.

```html
<iframe id="technician-age-growth" src="https://strokeofluck.github.io/ncsu-campus-voting/article/editor-visual-age-growth-20261109-v2.html?view=1" title="Age-group voting comparison" style="display:block;width:100%;height:900px;border:0" loading="lazy" scrolling="auto"></iframe>
<script>(()=>{const frame=document.getElementById('technician-age-growth');addEventListener('message',e=>{if(e.source!==frame.contentWindow||e.origin!==new URL(frame.src).origin||e.data?.type!=='technician-visual-height')return;const h=Number(e.data.height);if(Number.isFinite(h)&&h>=200&&h<=30000)frame.style.height=Math.ceil(h)+'px';});})();</script>

```
