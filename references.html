Early voting

OFFICIAL DOWNLOAD FOLDER

NCSBE — November 3, 2026 election data

Official directory containing the 2026 absentee / early-voting source already used by this project.

Browse the 2026 election download folder. The directory contains ballot records, county and statewide counts, demographic request statistics, polling places and other election files. These files serve different purposes; the campus-site comparison uses the by-county absentee archive below.

NCSBE file descriptions and update schedule. Absentee data include in-person early voting; during early voting, records for ballots cast are added the following day. A file's modification date is not itself the last voting date covered.

SITE RECORD

NC State — 2026 early-voting location

NC State identifies the 2026 campus early-voting site as Western Boulevard Business Services, 1220 Varsity Drive. Use this university listing for the location; use the NCSBE ballot records for participation and demographics.

Pack the Polls — 2026 election FAQs

The ballot records do not identify NC State enrollment or establish that the location change caused a change in student participation. Ages 18–24 are a college-age proxy, not a verified student population.
